Quick Start

$ git clone https://github.com/davis-asish/NeuralStyleTransferApp.git
$ cd NeuralStyleTransferApp
$ docker build -t neural-style-app .
$ docker run -p 5000:5000 neural-style-app

# Open http://localhost:5000

Features

🖼️ Text-to-Image

Generate any image from a text prompt using stabilityai/sd-turbo via Hugging Face diffusers pipeline.

🎭 Image Stylization

Upload any photo and transform it with one of 6 pre-tuned artistic style presets using img2img pipeline.

⚡ GPU / CPU

Automatically detects CUDA. Falls back to CPU gracefully — works on any modern machine.

🐳 Docker

Full environment containerized. One docker run command, zero setup friction.
